// how it works

Three keys. Zero fumbling.

01

Summon

Press ⌘ \ anywhere — the overlay fades in above your call, always on top, click-through when you want it.

02

Start listening

One click and Cue transcribes the meeting on-device, keeping a rolling transcript of who said what.

03

Ask for your line

Press ⌘J when you're put on the spot. Cue reads the moment and hands you the words — speak it almost verbatim.

// install

Unzip, open, done.

Builds aren't notarized by Apple yet, so macOS flags the download as "damaged" — it isn't. One Terminal command clears the quarantine flag; after that it opens like any other app.

macOS — install.log
# 1. download the .zip for your chip — arm64 = Apple Silicon, plain = Intel
# 2. unzip → drag Cue.app into Applications
# 3. if macOS says "Cue is damaged" — it isn't; clear the quarantine flag:
$ xattr -cr /Applications/Cue.app
✓ open Cue and press ⌘ \ · grant Screen Recording + Microphone when asked
windows — install.log
# 1. run Cue-Setup-<version>.exe
# 2. SmartScreen may warn → More info → Run anyway
✓ press Ctrl \ to summon the overlay
// bring your own claude

Two ways to power it.

Option A · Subscription

Claude Code CLI

Already pay for Claude? Install the Claude Code CLI and log in once:

npm i -g @anthropic-ai/claude-code → run claude

Cue auto-detects it. No API billing — it rides your existing subscription.

Option B · API key

Anthropic API

Grab a key at console.anthropic.com and paste it into Cue's Settings (the gear in the overlay). Pay-per-use on your Anthropic account.

Stored encrypted via your OS keychain — sent only to Anthropic, never to any Cue server.

// privacy

Local-first, on purpose.

🎙

Audio stays home. Transcription is on-device Whisper. Recordings and transcripts live only on your machine.

↯

Minimal egress. Only the screenshot or transcript text you explicitly ask about is sent to Claude — nothing on a timer.

⌗

Keys in the keychain. Your API key is encrypted at rest by the OS and never written in plaintext.

🫥

OS-level protection. Cue asks macOS and Windows to exclude the overlay from supported capture software. Full-display compatibility can vary by app and OS version.

⚖️ Recording meetings can be subject to all-party-consent laws where you live. You're responsible for getting any consent required before recording anyone — read the Terms and Privacy Policy.
